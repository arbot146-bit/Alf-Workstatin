## Prompt Format Trends (2026)

### Midjourney v6.1
- Uses `--ar`, `--stylize`, `--style raw`, `--quality`, `--personalize`, `--chaos`, `--v 6.1`

## Prompt Engineering Best Practices (from PromptHero examples)

### Photography Prompts
- Camera/lens: `shot on hasselblad x2d 100c, xcd 90mm f/2.5`
- Aperture: `f/1.4`, `mimics a large aperture`
- Lighting: `cinematic sepia color grading with golden hour warmth`
- Color: `dramatic black silhouette against burnt umber to honey amber gradient backdrop`
- Quality: `ultra sharp details, raw format, hyper realistic, 16K`

### Anime/Illustration Prompts
- Studio references: `animated by Kyoto Animation, Studio Ghibli, Miyazaki`
- Artist references: `Artgerm, Paul Lewin, Kehinde Wiley, Greg Rutkowski`
- Style tags: `Digital 2D, cel shading, vivid colors, ambient lighting`

### Cinematic/Realistic Prompts
- Start with: `realistic cinematic image with dark shadows and high contrast`
- Add camera specs: `shot on 35mm film, Sony A7III`
- Define lighting: `professional main fresnel light at 60 degree angle with silk diffusion`
- Include atmosphere: `haze machine for ethereal atmosphere, feathered shadows`
